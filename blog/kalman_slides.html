Kalman Filter Theory

A visual guide to 1D State Estimation

📐 What is a Kalman Filter?

The Kalman Filter is an optimal estimator that combines:

  • Predictions from a physics model (blue curve)
  • Measurements from noisy sensors (red curve)
  • To produce the best estimate (green curve)

It's used in GPS navigation, self-driving cars, rockets, and aircraft.

🔄 The Two-Step Process

1. Predict Step:

x̂⁻ = x̂ + velocity
P⁻ = P + Q

Use physics to predict where we'll be next. Uncertainty increases by Q (process noise).

2. Update Step:

K = P⁻ / (P⁻ + R)
x̂ = x̂⁻ + K(z - x̂⁻)
P = (1 - K)P⁻

Combine the prediction with the sensor measurement. The Kalman Gain (K) decides how much to trust each source.

⚖️ Understanding Kalman Gain (K)

The Kalman Gain balances trust between physics and sensors:

  • K ≈ 1: Trust the sensor (GPS) more
  • K ≈ 0: Trust the physics model more
  • K ≈ 0.5: Balance both equally

K automatically adjusts based on the relative uncertainties (P and R).

🎛️ Key Parameters

R (Measurement Noise): How noisy is the GPS sensor? Higher R = less trust in measurements.

Q (Process Noise): How unpredictable is the motion? Higher Q = more uncertainty in predictions.

P (Estimate Uncertainty): How confident are we in our current estimate? Lower is better.

🧪 Try This

  • Set R low (slider left) → Filter trusts GPS heavily
  • Set R high (slider right) → Filter relies on physics
  • Set Q high → Filter becomes more responsive to measurements
  • Use Manual Mode to step through one prediction-update cycle at a time
